# CAMS — Campus Asset Management System

A web-based platform for managing and accessing campus resources from one centralized system.

## Features

* 🔐 User Signup and Login
* 📦 Browse and manage campus assets
* 📋 Request campus equipment
* 📊 Dashboard for managing resources
* 👤 User profile management
* 🖼️ Image-based asset information
* ☁️ Backend support for file uploads

## Tech Stack

### Frontend

* React.js
* Vite
* JavaScript
* HTML/CSS

### Backend

* Node.js
* Express.js

### Database

* PostgreSQL

### Other Tools

* Git & GitHub
* REST APIs

## Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/Sandhya9381/CAMS.git
cd CAMS
```

### 2. Start the frontend

```bash
cd client
npm install
npm run dev
```

### 3. Start the backend

Open another terminal:

```bash
cd server
npm install
node server.js
```

The frontend and backend will then run locally on their respective development ports.

## Purpose

CAMS is designed to provide a centralized platform for educational institutions to organize, discover, request, and manage campus resources efficiently.
